# Screenshots

Current workspace captures are generated by `scripts/capture_showcase.py` from the running application with Playwright. The gear animation combines 60 actual WebGL viewer frames using Pillow.

| File | View |
| --- | --- |
| dashboard-new.png | Role-specific ECR queue, recent activity and secondary state charts |
| bom-tree.png | Expanded bicycle structure and indented guide lines |
| compare-diff.png | Frame A/B comparison: additions, removals and quantity changes |
| ecr-detail.png | Rejection comments, revision state, decisions and audit history |
| viewer.gif | Rotating spur gear with bore, dimensions and triangle count |
| viewer-gear.png | Gear viewer still |
| viewer-flange.png | Six-hole inspection flange |
| viewer-brake-disc.png | Slotted brake rotor |
| viewer-rim.png | Procedural toroidal bicycle rim |
| dashboard.jpg | Retained original dashboard capture |
| compare.jpg | Retained original comparison capture |
| stl-viewer.jpg | Retained original STL viewer capture |

Recreate the current gallery with the seeded API and Vite running:

```sh
python -m pip install -r scripts/requirements.txt
python -m playwright install chromium
python scripts/capture_showcase.py
```

Installed Chrome is used automatically on Windows. Screenshots use demo accounts and preserve engineering records. Additional desktop/mobile verification captures and the page-error report go to `.local/browser-qa/`.
